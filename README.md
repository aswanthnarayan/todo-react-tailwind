# Done It

## Description
Built a modernized note-taking application with React.js featuring a minimalist UI design and smooth user interactions. Engineered responsive layouts and dynamic components using Tailwind CSS with a mobile-first approach.

## Live Demo
Check out the live application at [Done It Live](https://done-it-todo.netlify.app/).

## Installation
1. Clone the repository:
   ```bash
   git clone git@github.com:aswanthnarayan/todo-react-tailwind.git
   cd todo-react-tailwind
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

## Usage
To run the application:
1. Start the development server:
   ```bash
   npm run dev
   ```
2. Access the application at `http://localhost:5173`.

## Scripts
- **dev**: Runs the development server using Vite.
- **build**: Builds the application for production.


## Dependencies
- **@material-tailwind/react**: For UI components styled with Tailwind CSS.
- **react**: JavaScript library for building user interfaces.
- **react-dom**: Provides DOM-specific methods for React.
- **react-hot-toast**: For displaying notifications.
- **react-icons**: For using popular icons in React applications.
- **uuid**: For generating unique identifiers.
